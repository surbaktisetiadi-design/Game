# 🎓 EduVenture 3D

Game edukasi 3D berbasis **Three.js (r160)** dengan arsitektur **OOP (Object-Oriented Programming)** murni tanpa build tool (langsung berjalan di browser atau GitHub Pages).

## Cara Menjalankan
1. Ekstrak file ZIP ini.
2. Karena menggunakan ES Modules (`importmap`), jalankan menggunakan server lokal seperti:
   - VS Code **Live Server**, atau
   - Python: `python -m http.server 8000` lalu buka `http://localhost:8000`
3. Atau langsung upload semua isi folder ke **GitHub Pages**.
